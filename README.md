# game-golem-witch

在一个架空的中世纪魔法世界里，玩家扮演一名魔女，用符文为哥雷姆编写程序，让它们自动完成生产。编程与自动化是核心玩法，基地建设和冒险作为辅助元素。

## 原型方向

原型完全采用 HTML 开发，方便通过浏览器远程试玩。当前试玩设备为手机，界面优先按手机竖屏和触控设计。让关键数值在窄屏上容易读，常用操作可直接点按。具体系统在制作和试玩中逐步探索，剧情与最终目标留待以后决定。

地图移动是核心玩法之一。地点是节点，通路是边，哥雷姆可以沿哪些路线移动由通路决定。地点也可以探索多层嵌套，例如在庭院内展开查看中庭和仓库。

## 开场原型

使用 Vue 3 和 Vite。资源栏显示工坊库存、公共魔力和金钱，所有数量初始为 0，均无游戏上限。魔力用于施法和驱动哥雷姆，土、气、水、火四种符文分别计数，可用于编程、合成材料或制造装置，金钱用于交易。

从魔女的房间出发，点按地图上相邻的地点即可沿路往返。魔女宅邸内的房间、庭院、入口、工坊两两直连。外部的矿山与宅邸相连，进出须经过入口。可随时展开或收起宅邸查看道路，视图切换保留当前位置。在房间启动冥想，每秒产生 10 魔力，离开房间结束。冥想期间仍可查看地图和操作符文板。在庭院的魔力之泉汲水、在矿山采土，每次获得 1 枚符文。魔女随身共可携带 10 枚，在工坊点「全部存入工坊」后可用于锻造和装入程序。移动和手动采集免费，刷新页面重新开始。

工坊里的魔力锻炉可制造哥雷姆。每具消耗 10 枚土符文、5 枚水符文和暂定的 1 点魔力。凑齐配方后即可锻造，工坊显示已有数量。

本地运行使用 Node.js 22.12+ 和 npm，先执行 `npm ci`，再执行 `npm run dev`。执行 `npm run build` 会生成可直接在浏览器中打开的单文件 `dist/index.html`。

## 哥雷姆的符文板

工坊锻造的每具哥雷姆有独立程序、当前位置和 5 格货舱。锻造消耗沿用上述配方。自动循环每秒尝试执行一行，单步和自动执行每成功一行消耗 1 魔力。自动运行时魔力耗尽会停留在当前行，并在重新供能后继续。每行第一枚符文是操作符，后续符文是五进制操作数（无、水、土、气、火依次为 0–4）。水走当前地点的指定出口；土使用当地指定交互点一次。1 号交互点在矿山和泉边分别装入一枚土或水，在工坊按装入顺序卸下一枚到全局库存。无效编号、满舱采集或空舱卸货会停在当前行。

从零试玩六行运土范例，共需 1 魔力、13 土、14 水（含锻造与编程用量）。锻造后打开符文板，填入范例或使用网页符文键盘编排草稿。键盘提供五枚符文、换行和退格。长按文本可用系统选区、剪切、复制与粘贴。内嵌符文字体将五个汉字显示为元素图标，可在符文板切回文字；复制到其他应用时仍为原汉字及换行。每具哥雷姆保留独立草稿，编辑期间旧程序继续运行；点「装入哥雷姆」时按新旧程序的符文差额结算库存，成功后停在新程序首行。清空草稿再装入会归还全部符文。可单步、自动循环或暂停；程序末尾回到首行，位置与货物保留。离开符文板后已启动的哥雷姆继续工作。

用 `npm run build -- --mode editor-demo` 构建符文板试玩入口，初始在工坊，已装入运土范例，库存余土、水各 6 枚，预存 60 魔力。

## 修复索道，解锁火

矿山隔岸是旧窑场。矿山交互点 1 继续采土，交互点 2 是索道水槽。魔女可将背包里的水批量投入，哥雷姆每次交互投入一枚。累计投入 150 枚水后，索道永久开放至本局结束。矿山 2 号出口通往旧窑场，窑场 1 号出口返回矿山。魔女或哥雷姆首次从余烬中采火便解锁火符文；窑场交互点 1 之后仍可采火。

五格满载运水路线从工坊的 2 号出口进庭院，采五枚水，走庭院 1 号出口回工坊，再沿工坊 1 号、入口 1 号出口到矿山。在水槽交互五次，再走矿山 1 号、入口 2 号出口回工坊。每圈 16 步，耗 16 魔力，送 5 水。满槽后再向水槽交货会停机，剩余货物保留。
