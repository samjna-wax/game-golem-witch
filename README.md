# game-golem-witch

在一个架空的中世纪魔法世界里，玩家扮演一名魔女，用符文为哥雷姆编写程序，让它们自动完成生产。编程与自动化是核心玩法，基地建设和冒险作为辅助元素。

## 原型方向

原型完全采用 HTML 开发，方便通过浏览器远程试玩。当前试玩设备为手机，界面优先按手机竖屏和触控设计。让关键数值在窄屏上容易读，常用操作可直接点按。具体系统在制作和试玩中逐步探索，剧情与最终目标留待以后决定。

地图分为宅邸、宅邸外、工坊内部。同层地点全连通，使用固定地点编号。工坊用编号列表表示。

## 开场原型

使用 Vue 3 和 Vite。悬浮顶栏可在资源、地图、哥雷姆三页间切换。资源页显示公共魔力进度条、工坊库存、背包和金钱。完整游戏从零开始，魔力初始上限为 200，工坊每种符文的初始上限为 100。魔力用于施法和驱动哥雷姆，土、气、水、火四种符文分别计数，可用于编程、合成材料或制造装置，金钱用于交易。

从魔女的房间出发，点按编号前往同层地点，在门口点「穿门」进入另一层。工坊与宅邸各有内外两侧门，地图与符文板的地点表可查所有编号与门的去向。在房间启动冥想，每秒产生 10 魔力，离开房间结束。冥想期间仍可查看地图和操作符文板。在庭院的魔力之泉汲水、在矿山采土，每次获得 1 枚符文。魔女随身共可携带 10 枚，在工坊仓库点「存入工坊」后可用于锻造和装入程序。满仓的符文留在背包；哥雷姆向满仓卸货时停机并保留货物。移动和手动采集免费，刷新页面重新开始。

工坊里的魔力锻炉可制造哥雷姆。每具消耗 10 枚土符文、5 枚水符文和暂定的 1 点魔力。凑齐配方后即可锻造，工坊显示已有数量。

本地运行使用 Node.js 22.12+ 和 npm，先执行 `npm ci`，再执行 `npm run dev`。执行 `npm run build` 会生成可直接在浏览器中打开的单文件 `dist/index.html`。

## 哥雷姆的符文板

工坊锻造的每具哥雷姆有独立程序、当前位置和 5 格货舱。锻造消耗沿用上述配方。自动循环每秒尝试执行一行，单步和自动执行每成功一行消耗 1 魔力。自动运行时魔力耗尽会停留在当前行，并在重新供能后继续。每行第一枚符文是操作符，后续符文是五进制操作数（无、水、土、气、火依次为 0–4）。水 n 前往本层 n 号地点，土 0 在门口穿至另一侧。无从开局就可免费书写，运行含无的指令仍耗魔。土 n 使用当地指定交互点一次。1 号交互点在矿山和泉边分别装入一枚土或水，在仓库按装入顺序卸下一枚到全局库存。无效编号、满舱采集或空舱卸货会停在当前行。

初始仓库在 1 号位，十二行运土范例从工坊门内侧出发并回到原位。含锻造和程序共需 1 魔力、17 土、15 水，运行另耗魔力。锻造后切到「哥雷姆」页，填入范例或使用网页符文键盘编排草稿。键盘提供五枚符文、换行和退格。长按文本可用系统选区、剪切、复制与粘贴。内嵌符文字体将五个汉字显示为元素图标，可在符文板切回文字；复制到其他应用时仍为原汉字及换行。每具哥雷姆保留独立草稿，编辑期间旧程序继续运行；点「装入哥雷姆」时按新旧程序的符文差额结算库存，成功后停在新程序首行。「编辑符文」和「执行程序」可分别打开。点「清空并重写」立即停机、清空草稿和已装程序，并退还占用的符文。清空或换装时，超过库存上限的退还部分会消散，编辑页会预先显示数量。位置和货舱保留，新程序装入后从第一行待命。可单步、自动循环或暂停；程序末尾回到首行，位置与货物保留。切到其他标签页后已启动的哥雷姆继续工作。「执行程序」中的「一键回程」消耗 10 魔力，把选中的哥雷姆送回工坊并丢弃货舱中所有物品。回程保留程序，停在首行待命。

用 `npm run build -- --mode editor-demo` 构建符文板试玩入口，初始在工坊，已装入运土范例，库存余土、水各 6 枚，预存 60 魔力。

## 修复索道，解锁火

矿山隔岸是旧窑场。矿山交互点 1 继续采土，交互点 2 是索道水槽。魔女可将背包里的水批量投入，哥雷姆每次交互投入一枚。累计投入 150 枚水后，索道永久开放至本局结束。开启后可在宅邸外使用水 2 前往旧窑场，水 0 返回宅邸门外侧。魔女或哥雷姆首次从余烬中采火便解锁火符文，窑场交互点 1 之后仍可采火。

## 工坊与基础魔力炉

工坊内 0 号位是门与哥雷姆锻造点。1 至 4 号位均可选址，最多容纳 3 座建筑，开局仓库占用 1 号位。进入空地，用工坊库存的 50 土、10 火、10 水造一座基础魔力炉。在建筑面板可将它迁往另一空位，炉内燃料与计时随建筑移动。地点编号始终固定，程序仍访问原编号。

魔女可从背包投一枚火，也可先从仓库取火再送入炉中。哥雷姆在炉位执行土 1 会从货舱投入一枚火。每炉独立计时，每 3 秒消耗 1 火生成 10 魔力。没有燃料或魔力余量不足 10 点时计时暂停。仓库库存、程序符文和炉内燃料分别记账。

用 `npm run build -- --mode workshop-demo` 构建工坊试玩入口。初始已开放索道，预备一具哥雷姆、建炉材料和一份向 2 号位送火的草稿。建炉后可装入运行。该程序每圈 20 步满载 5 火，在燃料全部转化且有魔力余量时净产 30 点魔力。
