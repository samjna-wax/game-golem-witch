# game-golem-witch

在一个架空的中世纪魔法世界里，玩家扮演一名魔女，用符文为哥雷姆编写程序，让它们自动完成生产。编程与自动化是核心玩法，基地建设和冒险作为辅助元素。

## 原型方向

原型完全采用 HTML 开发，方便通过浏览器远程试玩。当前试玩设备为手机，界面优先按手机竖屏和触控设计。让关键数值在窄屏上容易读，常用操作可直接点按。具体系统在制作和试玩中逐步探索，剧情与最终目标留待以后决定。

世界地图的 1 号是宅邸，2 号是矿山。宅邸内的 2 号是工坊，矿山内的 1 号是矿洞、2 号是旧窑场。同层地点全连通，使用固定地点编号。工坊用编号列表表示。

## 开场原型

使用 Vue 3 和 Vite。悬浮顶栏可在资源、地图、哥雷姆三页间切换。资源页显示公共魔力进度条、工坊库存、背包和金钱。完整游戏从零开始，魔力初始上限为 300，工坊每种符文的初始上限为 100。魔力用于施法和驱动哥雷姆，土、气、水、火四种符文分别计数，可用于编程、合成材料或制造装置，金钱用于交易。

从魔女的房间出发，点按编号前往同层地点，有内部地图的地点会自动进入。点 0 号从当前层的任意位置退出到上一层的门外，点同一编号可再次进入。地图与符文板显示从世界地图起的完整路径。在房间启动冥想，每秒产生 15 魔力，离开房间结束。冥想期间仍可查看地图和操作符文板。在庭院的魔力之泉汲水、在矿洞采土，每次获得 1 枚符文。魔女随身共可携带 10 枚，在工坊仓库点「存入工坊」后可用于锻造和装入程序。满仓的符文留在背包；哥雷姆向满仓卸货时等待并保留货物，库存有空位后自动继续。移动和手动采集免费，刷新页面重新开始。

工坊里的魔力锻炉可制造哥雷姆。每具消耗 10 枚土符文、5 枚水符文和 20 点魔力。凑齐配方后即可锻造，工坊显示已有数量。

本地运行使用 Node.js 22.12+ 和 npm，先执行 `npm ci`，再执行 `npm run dev`。执行 `npm run build` 会生成可直接在浏览器中打开的单文件 `dist/index.html`。

## 哥雷姆的符文板

工坊锻造的每具哥雷姆有独立程序、当前位置和 5 格货舱。锻造消耗沿用上述配方。自动循环每秒尝试执行一行，单步和自动执行每成功一行消耗 1 魔力。自动运行时魔力耗尽会停留在当前行，并在重新供能后继续。每行第一枚符文是操作符，地点和标签编号用五进制书写（无、水、土、火、气依次为 0–4）。水 n 前往本层 n 号地点，有内部地图时直接进入。水 0 从当前层退出，世界地图没有出口。无从开局就可免费书写，运行含无的指令仍耗魔。土 n 使用当地指定交互点一次。1 号交互点在矿洞和泉边分别装入一枚土或水，在仓库按装入顺序卸下一枚到全局库存。行动受阻时停在当前行，不消耗魔力；自动运行会每秒重试，条件允许后继续。无效编号等无法自行恢复的情况需要修改程序或手动处理。

初始仓库在 2 号位，十行运土范例从工坊出发，每圈带回一枚土并在仓库卸货。含锻造和程序共需 40 魔力（锻造 20 点、装入 20 点）、15 土、17 水，运行另耗魔力。锻造后切到「哥雷姆」页，填入范例或使用网页符文键盘编排草稿。键盘提供五枚符文、换行和退格。长按文本可用系统选区、剪切、复制与粘贴。内嵌符文字体将五个汉字显示为元素图标，可在符文板切回文字；复制到其他应用时仍为原汉字及换行。每具哥雷姆保留独立草稿。新锻造或重置后可编辑、清空、装入符文。成功装入非空程序或开始执行已保留的程序后，再次编辑前须重置。暂停或循环回首行仍须重置。每次成功装入均按整份新程序的长度收取魔力，每枚符文（含无）1 点，换行不计。符文库存仍按新旧程序的材料差额结算。库存或魔力不足时保留草稿和原程序。卸下程序免费，已消耗的装入魔力不退。成功换装后停在新程序首行。「执行程序」中的「复制完整程序」会复制当前哥雷姆已装入的符文及换行，可直接粘贴到另一具哥雷姆的草稿。点「清空并重写」立即停机、清空草稿和已装程序，并退还占用的符文。清空或换装时，超过库存上限的退还部分会消散，编辑页会预先显示数量。位置和货舱保留，新程序装入后从第一行待命。可单步、自动循环或暂停；程序末尾回到首行，位置与货物保留。切到其他标签页后已启动的哥雷姆继续工作。「重置并回程」消耗 10 魔力，把选中的哥雷姆送回工坊并丢弃货舱中所有物品。重置后保留程序和草稿，寄存器归零，停在工坊入口、首行待命。

用 `npm run build -- --mode editor-demo` 构建符文板试玩入口，初始在工坊，已装入运土范例，库存余土、水各 6 枚，预存 60 魔力。

## 修复索道，解锁火

矿山隔岸是旧窑场。矿洞交互点 1 继续采土，交互点 2 是索道水槽。魔女可将背包里的水批量投入，哥雷姆每次交互投入一枚。累计投入 150 枚水后，索道永久开放至本局结束。开启后可在矿山使用水 2 进入旧窑场，水 1 前往余烬堆，在此使用土 1 采火。魔女或哥雷姆首次从余烬中采火便解锁火符文。

## 工坊与基础魔力炉

工坊共有 4 个建筑位，可建 4 座建筑。1 号固定为哥雷姆锻造炉，开局 2 号是仓库，3、4 号可建魔力炉。进入空地，花费 50 魔力和工坊库存的 50 土、10 火、10 水造一座基础魔力炉。在建筑面板可将它迁往另一空位，炉内燃料随建筑移动。地点编号始终固定，程序仍访问原编号。

魔女可从背包投一枚火，也可先从仓库取火再送入炉中。哥雷姆在炉位执行土 1 会从货舱投入一枚火。每座炉每秒消耗 1 火，生成 10 魔力。魔力储量剩余空间不足 10 点时保留燃料，腾出空间后继续燃烧。仓库库存、程序符文和炉内燃料分别记账。

用 `npm run build -- --mode workshop-demo` 构建工坊试玩入口。初始已开放索道，预备一具哥雷姆、建炉材料和一份向 3 号位送火的草稿。建炉后可消耗 40 魔力装入这份 20 行的运火程序。该程序每圈 20 步满载 5 火，在燃料全部转化且有魔力余量时净产 30 点魔力。

## 运气回库，解锁运算与跳转

修好索道后，从矿山用水 2 进入旧窑场。1 号为余烬堆，3 号为风井，仅哥雷姆可到达风井。水火进入风井，土水采一枚气，水无回到矿山的旧窑场门外，再用水无退出矿山。第一枚气由哥雷姆在仓库成功卸货后，所有哥雷姆开启以下指令。气在货舱中或回程时被丢弃均不触发解锁。

| 原文 | 作用 |
| --- | --- |
| 火 x | 选中 x 号寄存器，加一。1 至 4 分别为水、土、火、气 |
| 气 n | 当前寄存器非零时减一并跳至标签 n；为零时保持零并继续下一行 |
| 无 n | 标记当前行为编号 n 的标签 |

每行只有一个操作符和一个五进制操作数。寄存器为每具哥雷姆独立的 BigInt 自然数。初始选中水，执行火才切换当前寄存器。移动、交互、标签、暂停和末尾循环均保留当前选择；换装、卸下程序或回程时清零并重新选中水。「火土」接「气 n」一定跳转，土值恢复原值，当前选中土。标签和跳转也各占一步、消耗 1 魔力。装入时校验指令和整份程序的标签；重名及缺失目标会阻止装入。装入和材料费用仍按既有规则计算。

用 `npm run build -- --mode air-demo` 生成运气试玩入口，开场已取得火，气库存为零，预填从工坊出发采三枚气并送回仓库的草稿。到货后可在空草稿中填入计数范例。
